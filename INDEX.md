# src/ — индекс .vue (Vue 3 + PrimeVue)

## browse_dialog/
- **BrowseDialogApp.vue** — диалог выбора пути (файл/папка) через бэкенд `list_dir` (браузер не отдаёт реальный путь). Props: mode, startPath, ext, onSelect, onClose. Вызывается всеми редакторами.
- **main.js** — точка входа Vue/PrimeVue для диалога: `openBrowseDialog({mode, startPath, ext, onSelect})` — та же сигнатура, что у старого `web/browse_dialog.js`; Vite-вход `browse_dialog` (vite.config.js) собирает её в `web/browse_dialog.js` (outDir `web`, fileName = имя входа), поэтому вызывающие не меняются. Создаёт container в `document.body`, монтирует `BrowseDialogApp`, подключает PrimeVue, линкует стили через `shared/styles_link.js`. Используется: `web/script_editor.js`, `web/script_library.js`, `web/vo_dub_library.js` (через собранный `web/browse_dialog.js`).

## line_editor/
- **LineEditorApp.vue** — главный диалог: редактор строк аудиокниги. Спикер/роль, instruct, текст, ударения, паузы, merge/split, hash-файлы (`lineHash`, `makeLineFilename`), сохранение в JSON с дебаунсом.
- **SpeakerPickerDialog.vue** — stateless-пикер CosyVoice-пресетов спикеров; эмитит выбранный пресет.
- **main.js** — точка входа Vue/PrimeVue для редактора: `openLineEditor({folder, filename, suffix, checkedApi, revoiceApi})` — та же сигнатура, что у старого `web/line_editor.js`; Vite-вход `line_editor` собирает её в `web/line_editor.js`. Создаёт container в `document.body`, монтирует `LineEditorApp`, подключает PrimeVue и `ConfirmationService`. Используется: `web/script_library.js` (через собранный `web/line_editor.js`), дальше — из дерева панели Script Library.

## roles_editor/
- **RolesEditorApp.vue** — редактор `_roles.json`: только `speaker` редактируется (код/имя/описание read-only). Дебаунс-сохранение. Источник истины для резолвинга ролей.
- **main.js** — точка входа Vue/PrimeVue для редактора ролей: `openRolesEditor({root, suffix})` — та же сигнатура, что у старого `web/roles_editor.js`; Vite-вход `roles_editor` собирает её в `web/roles_editor.js`. Создаёт container в `document.body`, монтирует `RolesEditorApp`, подключает PrimeVue. Используется: `web/script_library.js` (через собранный `web/roles_editor.js`).

## script_library/
- **ScriptLibraryPanel.vue** — инлайн-панель в ноде FL_CosyVoice3_ScriptLibrary: дерево act/script + мост к ComfyUI-виджетам (реактивные копии, запись в `.value`). Patch `graphToPrompt`/`queuePrompt` — в `web/script_library.js`.
- **main.js** — точка входа Vue/PrimeVue для панели: `mountScriptLibraryPanel({node, folderWidget, actWidget, filterWidget, scriptFileWidget, openBrowseDialog, openRolesEditor, openLineEditor, queueLineRevoice})`. В отличие от диалогов — не плавающий оверлей: монтирует компонент в container, который `web/script_library.js` передаёт в `node.addDOMWidget`, и рендерится inline в теле самой ноды на канвасе. Vite-вход `script_library_panel` собирает её в `web/script_library_panel.js`. Возвращает `{element, unmount}`. Используется: `web/script_library.js` (через собранный `web/script_library_panel.js`).

## vo_dub_editor/
- **VoDubBrowserPanel.vue** — инлайн-панель в ноде FL_CosyVoice3_VODubLibrary: episode-бакееты со счётчиками статусов. Клик по бакеету → `VoDubLineEditor.vue`. Дерево по таймеру (3 c), root — в localStorage.
- **VoDubLineEditor.vue** — редактор одной строки VO dub (без merge/split/pause/hash-схемы — строки не перестраиваются). 🔁 рендер ставит граф в очередь с `line_override`, `output_path_override`, `effect_override`.
- **DubRolesEditorApp.vue** — редактор `_dub_roles.json` (casting document): только `speaker` редактируется, остальное read-only (файл генерируется заново). Роль определяется regex по `audio_key`.
- **WaveformCanvas.vue** — статичный waveform-overview (не плеер). Декодируется лениво, пагинация 50 строк/страниц.
- **effect_preview.js** — клиентское realtime-приближение эффектов из `nodes/_audio_effects.py`, применяемое к `<audio>` через Web Audio API: `createEffectPreview(el)` — один экземпляр на элемент (dry-путь + wet-пути по каждому previewed эффекту, `setEffect(name)` переключает gain, не перестраивает граф); `EFFECT_CHAINS` — radio, phone, muffled, radio_dry, intercom, suit (параметры совпадают с Python-рецептами); master-gate синхронизирован с `paused` (чтобы noise loop не гудел до play). Аудит-превью только, не сохраняется. Используется: `vo_dub_editor/VoDubLineEditor.vue`.
- **waveform.js** — `decodeWaveformPeaks(url, bucketCount=100)` — декодирует аудио в массив peak-магнитуд (0..1) по bucket'ам (только для просмотра, не playback); `decodeAudioData` как декодер; бросает на любой ошибке (решение о виде «не загрузилась» — в WaveformCanvas.vue). Используется: `vo_dub_editor/WaveformCanvas.vue`.
- **main.js** — три точки входа Vue/PrimeVue для VO Dub: `mountVoDubBrowserPanel({node, projectRootWidget, openBrowseDialog, openVoDubLineEditor, openDubRolesEditor, queueVoDubRender})` — инлайн-виджет ноды (аналог `mountScriptLibraryPanel`), монтируется в container от `web/vo_dub_library.js`; `openVoDubLineEditor({root, bucket, renderApi})` — плавающий диалог редактора строки; `openDubRolesEditor({root})` — плавающий диалог casting-редактора. Vite-вход `vo_dub_editor` собирает все три в один `web/vo_dub_editor.js`. Используется: `web/vo_dub_library.js` (через собранный `web/vo_dub_editor.js`).

## shared/
- **DialogHeader.vue** — общий заголовок диалога: title, status, preset-ширины, A−/A+, `after`-slot.
- **PanelWidthButtons.vue** — кнопки preset-ширины диалога (px + 100%).
- **FontSizeButtons.vue** — кнопки A−/A+ размера текста.
- **InstructPickerDialog.vue** — stateless-пикер фраз из `_instruct_categories.json` (с подсказкой «когда использовать»).
- **LineRowEditor.vue** — общий компонент строки для обоих редакторов. Prop/emit-driven, слоты `leading`/`trailing`. 3-root намеренно.
- **RoleDropdown.vue** — общий dropdown «спикер/роль». Резолвит по коду (`_roles.json`/`_dub_roles.json`). Editable: неизвестный код = литеральный пресет.
- **RoleInfoPopover.vue** — рендерная часть хука `useRoleInfoPopover`. Повер-окно пар [key, value]; экстрактор полей — у вызывающего.
- **StickyPanel.vue** — «прилипание кверху» ряда контролов при скролле.

### shared/*.js (не Vue)
- **audio_buffer_guard.js** — защита ленивого (`preload="none"`) `<audio>` от обрыва начала воспроизведения: `guardAgainstUnbufferedPlay(el)` — при `play` до `canplaythrough` сразу `pause`, затем `play` после `canplaythrough` (прозрачно для короткого локального клипа, нативные кнопки не трогаются); `waitUntilBuffered(el)` — Promise, резолвится, когда буфер достаточно, для скриптового `play` двух дорожек разом (чтобы не рассинхронизировать старты). Используется: `vo_dub_editor/VoDubLineEditor.vue`.
- **font_size.js** — хук `useFontSize({storageKey, defaultSize=13, min=9, max=22})` — общий контрол A−/A+ размера контента: reactive `fontSizePx`, persistence в localStorage (key = storageKey), `decrease`/`increase` с clamp. Используется: `browse_dialog/BrowseDialogApp.vue`, `line_editor/LineEditorApp.vue`, `line_editor/SpeakerPickerDialog.vue`, `roles_editor/RolesEditorApp.vue`, `shared/InstructPickerDialog.vue`, `vo_dub_editor/DubRolesEditorApp.vue`, `vo_dub_editor/VoDubLineEditor.vue`.
- **instruct_library.js** — write-side для `_instruct_categories.json`: `containsPhrase(categories, phrase)` — точное совпадение (trim) в существующих примерах; `addPhraseToCategories(categories, phrase)` — чистая функция, добавляет фразу в категорию `custom` (создаёт её, если нет), возвращает новый массив; `saveInstructPhrase(fileApi, categoriesPath, phrase)` — read-modify-write по актуальному содержимому файла через `fileApi` (read/write), возвращает обновлённый массив или null (пустая фраза / уже есть / файла нет). Используется: `line_editor/LineEditorApp.vue`, `vo_dub_editor/VoDubLineEditor.vue`.
- **line_hash.js** — контент-отпечаток строки, обязан совпадать байт-в-байт с `nodes/_line_audio.py` line_hash(): `lineHash(speaker, instruct, text)` — sha256(`"speaker|instruct|text"`, полей после trim) → первые 8 hex; `speaker` — уже RESOLVED пресет. `makeLineFilename(position, hash)` — `NNNN_hash.wav`; `parseLineFilename(name)` — обратно `{position, hash}` или null; `hasExpectedFile(filenames, position, hash)` — «записана ли строка под текущим контентом» (mirrors expected_path + os.path.isfile); `mostRecentAtPosition(filenames, fileMtimes, position)` — самый свежий файл на позиции (fallback mode 1, mirrors most_recent_at_position). Используется: `line_editor/LineEditorApp.vue`, `vo_dub_editor/VoDubLineEditor.vue`.
- **panel_width.js** — хук `usePanelWidth({storageKey, defaultWidth, presets, fullVw=94})` — общая «разрешаемая ширина диалога»: `cssWidth` (computed), `setWidth(value)` (localStorage; `"full"` = sentinel → fullVw vw), `presets`. Используется: `browse_dialog/BrowseDialogApp.vue`, `line_editor/LineEditorApp.vue`, `line_editor/SpeakerPickerDialog.vue`, `roles_editor/RolesEditorApp.vue`, `shared/InstructPickerDialog.vue`, `vo_dub_editor/DubRolesEditorApp.vue`, `vo_dub_editor/VoDubLineEditor.vue`.
- **role_info_popover.js** — хук `useRoleInfoPopover(roleEntries, fieldsFor)` — общий «наведи на код роли, увидишь её каталожную запись»: reactive `{popover, show(anchorEl, code), hide, info}`, position по getBoundingClientRect, `info` — computed (fields из fieldsFor(entry) или message). Используется: `line_editor/LineEditorApp.vue`, `vo_dub_editor/VoDubLineEditor.vue`.
- **speaker_accent.js** — стабильный дешёвый hash → hue: `speakerAccent(name)` — `hsl(hash%360, 55%, 55%, 0.3)` (одна и та же маппинг для `.line-rail` и аватаров пикера); `speakerInitials(name)` — двухбуквенный монограм (первая буква + следующая отличная). Используется: `line_editor/LineEditorApp.vue`, `line_editor/SpeakerPickerDialog.vue`.
- **stress_mark.js** — `insertStressMark(setStatus)` — вставка ударения (U+0301) в `document.activeElement` (textarea/input) по позиции курсора + dispatch input; использует mousedown+preventDefault на `<Button>` (click украл бы фокус). Используется: `line_editor/LineEditorApp.vue` (как `sharedInsertStressMark`), `vo_dub_editor/VoDubLineEditor.vue`.
- **styles_link.js** — `ensureStylesLinked(importMetaUrl)` — линкует собранный `web/style.css` (с `?v=STYLE_VERSION`) в `<head>` один раз; сам импортирует весь CSS (PrimeVue theme + primevue.min.css + primeicons + `sass/global.sass`) ровно в одном месте, чтобы Vite собирал тему один раз; `importMetaUrl` = `import.meta.url` вызывающего entry. Используется: все `main.js` (`browse_dialog`, `line_editor`, `roles_editor`, `script_library`, `vo_dub_editor`).
- **textarea_autogrow.js** — хук `useTextareaAutoGrow()` — «textarea растёт под контент и пересчитывается по требованию»: PrimeVue `auto-resize` реагирует только на собственный `input`, которого нет при `preventDefault` в onPaste (запись `el.value` напрямую) и при смене шрифта; Map key→DOM-нода, `autoGrow(el)`, `setTextareaRef(key, el)`, `regrowAll()`. Используется: `line_editor/LineEditorApp.vue`, `vo_dub_editor/VoDubLineEditor.vue`.

## Связи
- **Аудиокнига:** ScriptLibraryPanel → BrowseDialog → LineEditorApp / RolesEditorApp.
- **VO Dub:** VoDubBrowserPanel → VoDubLineEditor / DubRolesEditorApp.
- **Общие строки:** LineRowEditor + RoleDropdown + InstructPickerDialog + SpeakerPickerDialog + RoleInfoPopover (обоими редакторами).
- **Общий UI:** DialogHeader, PanelWidthButtons, FontSizeButtons, StickyPanel.
- **Entry points:** каждый `main.js` — отдельный Vite-вход (vite.config.js → `outDir: web`), собираемый в `web/<имя>.js` с публичным API, совместимым со старыми vanilla-файлами. ComfyUI-слой импортирует только собранные `web/*.js`; прямой импорт `src/*/main.js` запрещён (конфликт chunks).
