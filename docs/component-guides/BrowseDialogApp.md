# BrowseDialogApp.vue

## Назначение
`BrowseDialogApp.vue` — это Vue-порт старого модуля `web/browse_dialog.js`. Поскольку браузеры безопасности ради не передают реальный путь к файлу на файловой системе, этот компонент взаимодействует с собственным бэкендом ComfyUI (`list_dir`) для навигации по директориям и выбора файлов или папок.

## Режимы и использование
Компонент используется для диалогов выбора папки или файла внутри редакторов и нод.
Основные пропсы:
- `mode`: строка (`"folder"` или `"file"`), определяющая режим работы диалога.
- `startPath`: начальный путь для открытия.
- `ext`: фильтр расширений файлов (если применимо).
- `onSelect`: функция-коллбэк при выборе файла/папки.
- `onClose`: функция-коллбэк при закрытии диалога.

## Интерфейс
Основан на компонентах PrimeVue (`Dialog`, `Button`, `InputText`, `Message`), а также шапке `DialogHeader`. Поддерживает управление шириной панели и размером шрифта.
