# DialogHeader.vue

## Назначение
`DialogHeader.vue` — это общий компонент шапки для модальных диалоговых окон (`#header` слот). Объединяет заголовок, текст статуса, кнопки изменения ширины панели (`PanelWidthButtons`) и кнопки размера шрифта (`FontSizeButtons`), устраняя дублирование разметки в `RolesEditorApp`, `LineEditorApp`, `BrowseDialogApp` и др.

## Пропсы
- `title`: строка (`String`), заголовок диалога.
- `status`: строка (`String`), опциональный статус/сообщение.
- `widthPresets`: массив пресетов ширины панели.
- `setWidth`: функция для установки ширины.
- `fontSizeDecrease` / `fontSizeIncrease`: опциональные функции для изменения размера шрифта.

## Особенности реализации
Предоставляет стандартизированную верхнюю панель управления со встроенными кнопками изменения масштаба и ширины для всех основных диалогов приложения.
