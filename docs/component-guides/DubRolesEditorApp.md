# DubRolesEditorApp.vue

## Назначение
`DubRolesEditorApp.vue` — редактор ролей для проектов VO Dub (дубляжа). В отличие от классического `RolesEditorApp.vue` (работающего со списком в `_roles.json`), здесь `_dub_roles.json` представляет собой полноценный кастинг-документ (словарь, где ключ — код роли), содержащий персонажа, гендер, актера и описание (согласно бэкенду `nodes/vo_dub_library.py`).

## Пропсы
- `root`: строка (`String`), корневая папка проекта.
- `onClose`: функция-коллбэк (`Function`) при закрытии редактора.

## Особенности реализации
Предоставляет интерфейс для управления кастингом голосов в проектах дубляжа с сохранением данных в структуру `_dub_roles.json`.
