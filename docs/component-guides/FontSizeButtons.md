# FontSizeButtons.vue

## Назначение
`FontSizeButtons.vue` — пара кнопок уменьшения и увеличения размера шрифта ("A-" / "A+"), работающая в паре с композаблом `useFontSize` из `font_size.js`. Вынесена в отдельный компонент для переиспользования во всех диалогах.

## Пропсы
- `decrease`: функция (`Function`), вызываемая при уменьшении шрифта.
- `increase`: функция (`Function`), вызываемая при увеличении шрифта.

## Особенности реализации
Использует компоненты PrimeVue (`Button`) с иконками или текстом для удобной регулировки масштаба текста в окнах редакторов.
