# InstructPickerDialog.vue

## Назначение
`InstructPickerDialog.vue` — это диалоговое окно на базе карточек для выбора инструкций/регистров из файла банка фраз `_instruct_categories.json`. Выделено из выпадающего списка в `LineEditorApp.vue`, чтобы дать достаточно места для отображения детального описания "когда использовать данный регистр".

## Пропсы и события (Emits)
- **Пропсы:**
  - `visible`: булево (`Boolean`), управляет видимостью диалога.
  - `categories`: массив категорий инструкций (`Array`).
- **События (Emits):**
  - `update:visible`: управление видимостью (v-model).
  - `select`: передает выбранную инструкцию вызывающему компоненту.

## Особенности реализации
Автономный компонент-селектор выразительных инструкций TTS, обеспечивающий удобный выбор пресетов с подробными описаниями.
