# LineEditorApp.md

## Назначение
`LineEditorApp.md` (соответствует `LineEditorApp.vue`) — это главный и наиболее комплексный редактор строк сценария аудиокниги (`Line Editor`). Он предоставляет полноценный интерфейс для просмотра, редактирования, озвучки, настройки интонаций, проверки хэшей аудиофайлов и управления репликами актеров.

## Ключевые возможности
- Редактирование текста строк, назначение ролей и спикеров (`SpeakerPickerDialog`).
- Выбор и вставка интонационных пресетов (`InstructPickerDialog`).
- Вставка знаков ударения и управление ударениями (`stress_mark.js`).
- Поддержка всплывающих подсказок с информацией о роли (`RoleInfoPopover`).
- Автоматическое изменение размера текстовых полей (`textarea_autogrow.js`).
- Интеграция с модальными подтверждениями PrimeVue (`ConfirmDialog`, `useConfirm`) и общими элементами управления (`DialogHeader`, `StickyPanel`, `LineRowEditor`).

## Архитектура
Реализован как модальное диалоговое окно с поддержкой изменения ширины (`usePanelWidth`) и размера шрифта (`useFontSize`), управляющее массивом строк сценария и их генерацией.
