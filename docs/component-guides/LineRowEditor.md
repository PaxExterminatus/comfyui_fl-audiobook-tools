# LineRowEditor.vue

## Назначение
`LineRowEditor.vue` — это общий компонент для редактирования отдельной строки сценария, выделенный из `LineEditorApp.vue`. Он используется как в аудиокнижном редакторе строк (`LineEditorApp.vue`), так и в редакторе строк VO Dub (`VoDubLineEditor.vue`), чтобы обеспечить единый интерфейс и поведение полей строки без дублирования кода.

## Пропсы и события (Emits)
- **Пропсы:**
  - `speaker`: строка, текущий выбранный спикер/роль.
  - `roleEntries`: массив записей ролей для выпадающего списка.
  - `roleOptionSubLabel`: функция для получения подписи к роли.
  - `speakerPlaceholder`: плейсхолдер для поля спикера.
  - `instruct`: строка, текущая инструкция/регистр.
  - `instructCategories`: список категорий инструкций.
  - `text`: строка, редактируемый текст строки.
  - `showText`: логическое значение (показывать ли текстовое поле).
- **События (Emits):**
  - `update:speaker`, `update:instruct`, `update:text` (двусторонняя связь v-model).
  - `open-instruct-picker`, `undo-instruct`, `apply-instruct`.
  - `role-info-enter`, `role-info-leave`.

## Особенности реализации
Объединяет выпадающий список ролей (`RoleDropdown`), выбор инструкций (`InstructPickerDialog` / кнопки), а также поле ввода текста и кнопки управления в единую унифицированную строку редактирования.
