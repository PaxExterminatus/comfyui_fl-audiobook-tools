# MarkdownReader.vue

## Назначение
`MarkdownReader.vue` — компонент для чтения и отображения руководств в формате Markdown, созданных делегированными агентами (в рамках вкладки docs в dev-ui). Поддерживает вкладки для каждого компонента и вторичные вкладки для разных версий файлов.

## Особенности реализации
Использует Vite `import.meta.glob` для динамического обнаружения файлов документации в каталоге `docs/component-guides/`, парсит и отображает их с удобной навигацией по компонентам и версиям.
