# PanelWidthButtons.vue

## Назначение
`PanelWidthButtons.vue` — компонент для переключения ширины панели (пресеты в пикселях или "full"), работающий совместно с композаблом `usePanelWidth` (`panel_width.js`). Избавляет от дублирования разметки кнопок ширины между `RolesEditorApp` и `LineEditorApp`.

## Пропсы
- `presets`: массив пресетов ширины (`Array`).
- `setWidth`: функция (`Function`), принимающая выбранное значение ширины.

## Особенности реализации
Рендерит горизонтальный ряд кнопок для мгновенного изменения ширины модального окна в соответствии с предпочтениями пользователя.
