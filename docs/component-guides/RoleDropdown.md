# RoleDropdown.vue

## Назначение
`RoleDropdown.vue` — универсальный выпадающий список для выбора роли/спикера. Используется как в `LineEditorApp.vue` (для `_roles.json`), так и в `VoDubLineEditor.vue` (для `_dub_roles.json`), обеспечивая идентичное поведение при выборе и редактировании ролей.

## Пропсы и события (Emits)
- **Пропсы:**
  - `modelValue`: текущее значение роли (`String`).
  - `roleEntries`: массив записей ролей (`Array`).
  - `optionSubLabel`: функция для получения подписи к опции.
- **События (Emits):**
  - `update:modelValue`: двусторонняя привязка выбранной роли.

## Особенности реализации
Позволяет удобно искать и выбирать роли с поддержкой кастомных подписей и отображения метаданных через вспомогательные функции.
