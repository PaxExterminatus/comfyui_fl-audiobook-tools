# RoleInfoPopover.vue

## Назначение
`RoleInfoPopover.vue` — визуальная часть всплывающей подсказки о роли (реализует логику `useRoleInfoPopover` из `role_info_popover.js`). Компонент независим от конкретной структуры данных роли (так как форматы в `_roles.json` и `_dub_roles.json` отличаются) и просто отображает переданный массив пар `[key, value]`.

## Пропсы
- `visible`: булево (`Boolean`), отображать ли поповер.
- `left` / `top`: координаты позиционирования (`Number`).
- `message`: информационное сообщение (`String`).
- `fields`: массив полей для отображения (`Array`).

## Особенности реализации
Обеспечивает всплывающее окно с подробными метаданными роли при наведении или клике в интерфейсе списков и редакторов.
