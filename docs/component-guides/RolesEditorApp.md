# RolesEditorApp.vue

## Назначение
`RolesEditorApp.vue` — это Vue-компонент (порт старого `web/roles_editor.js`), предназначенный для управления ролями в проекте аудиокниги. Он считывает все роли из файла проекта `_roles.json` и позволяет пользователю переназначать "speaker" (реальный пресет CosyVoice, с которым сопоставляется код роли).

## Основные особенности
- **Защита целостности:** Код роли (ID), имя и описание отображаются только для чтения. Переименование кода роли могло бы нарушить ссылки на нее в существующих файлах сценария.
- **Автосохранение:** Изменения спикеров сохраняются обратно в `_roles.json` с дебаунсом (задержкой), выступая единственным источником истины, по которому Script Library разрешает роли (через `resolve_roles`).
- **Интерфейс:** Построен с использованием компонентов PrimeVue (`Dialog`, `Card`, `Message`, `Dropdown`, `Textarea`) и адаптивной сетки карточек (`.roles-list`). Поддерживает настройку ширины панели и размера шрифта через общие композаблы (`usePanelWidth`, `useFontSize`).

## Пропсы и API
Компонент управляет диалоговым окном редактора ролей, получая параметры через пропсы (например, корневую папку проекта и коллбэки закрытия) и взаимодействуя с бэкендом для загрузки и обновления списка ролей.
