# ScriptLibraryPanel.vue

## Назначение
`ScriptLibraryPanel.vue` — это панель управления библиотекой сценариев, встроенная в тело ноды ComfyUI (порт логики `web/script_library.js`). Отвечает за:
- Кнопку выбора проекта и сканирование структуры проекта.
- Две панели инструментов (tool rows).
- Дерево актов и скриптов с чекбоксами для массового выбора/очереди генерации.

## Архитектура и мост с виджетами ComfyUI
Компонент поддерживает синхронизацию с обычными виджетами ComfyUI (`folderWidget`, `actWidget`, `filterWidget`, `scriptFileWidget`). Поскольку Vue не может отслеживать мутации внешних объектов напрямую, компонент ведет собственное реактивное состояние и при любых изменениях обновляет свойство `.value` соответствующих виджетов ComfyUI, гарантируя корректную сериализацию воркфлоу независимо от того, смонтирована ли панель в данный момент.

## Пропсы
- `node`: ссылка на ноду ComfyUI.
- `folderWidget`, `actWidget`, `filterWidget`, `scriptFileWidget`: ссылки на соответствующие виджеты ноды.
- Входные точки для других редакторов передаются через пропсы (например, открытие браузера папок, редактора ролей, редактора строк и т.д.).
