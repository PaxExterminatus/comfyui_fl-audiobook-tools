# SpeakerPickerDialog.vue

## Назначение
`SpeakerPickerDialog.vue` — это диалоговое окно в виде сетки карточек для выбора сохраненных пресетов спикеров CosyVoice. Аналогичен по паттерну `InstructPickerDialog.vue`, но вместо категорий отображает карточки пресетов голосов.

## Пропсы и события (Emits)
- **Пропсы:**
  - `visible`: булево (`Boolean`), управляет видимостью диалога.
  - `presets`: массив пресетов спикеров (`Array`).
- **События (Emits):**
  - `update:visible`: управление видимостью (v-model).
  - `select`: эмитирует выбранный пресет спикера при клике на карточку.

## Особенности реализации
Является полностью автономным (stateless) компонентом: не знает, для какой конкретно строки выбирается спикер, передавая выбранный пресет родителю (например, `LineEditorApp.vue`) для дальнейшей обработки.
