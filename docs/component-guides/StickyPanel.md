# StickyPanel.vue

## Назначение
`StickyPanel.vue` — универсальная обертка для фиксации панели управления (sticky-to-top) внутри прокручиваемых контейнеров диалогов. Решает особенности верстки PrimeVue, где `.p-dialog-content` прокручивается целиком как единый блок.

## Особенности реализации
Гарантирует, что шапка с кнопками управления или фильтрами остается закрепленной наверху при прокрутке содержимого модального окна.
