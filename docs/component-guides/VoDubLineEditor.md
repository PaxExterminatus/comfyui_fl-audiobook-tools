# VoDubLineEditor.vue

## Назначение
`VoDubLineEditor.vue` — полноэкранный редактор для одного эпизода (bucket) в проекте голосового дубляжа (VO Dub). Разработан под архитектуру `nodes/vo_dub_library.py`: здесь нет классической схемы позиций/хэшей аудиокниг, операций слияния/разделения строк или пауз, а фокус сделан на генерации, воспроизведении и проверке дублированных реплик.

## Пропсы
- `root`: строка (`String`), путь к проекту.
- `bucket`: строка (`String`), имя текущего эпизода/бакета.
- `renderApi`: объект (`Object`), API для рендеринга реплик дубляжа.

## Особенности реализации
Интегрирует плееры, волновую визуализацию (`WaveformCanvas`), выбор ролей и интонаций для эффективного прослушивания и итеративного переозвучивания реплик по эпизодам.
