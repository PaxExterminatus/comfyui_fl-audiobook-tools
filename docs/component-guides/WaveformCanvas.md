# WaveformCanvas.vue

## Назначение
`WaveformCanvas.vue` — это легкий компонент для отрисовки статической формы звуковой волны (waveform) для конкретного аудиофайла. Он носит исключительно визуальный характер и не заменяет стандартный аудиоплеер (`<audio controls>`), располагающийся под ним в `VoDubLineEditor.vue`.

## Пропсы
- `src`: строка (`String`), путь или URL к аудиофайлу для визуализации.

## Логика работы
Компонент анализирует или загружает аудиоданные и строит на холсте (`Canvas`) простую визуализацию амплитуды сигнала в виде статической волны, обеспечивая наглядное представление аудиодорожки без избыточной интерактивности.
